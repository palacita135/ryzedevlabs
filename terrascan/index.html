Comprehensive Toolkit

Engineered for Heavy Drone Survey Missions

From civil engineering topography and agricultural health indices to high-fidelity 3D asset inspection — TerraScan replaces fragmented point solutions with an integrated pipeline.

High-Res 2D Orthomosaics

Sub-centimeter GSD orthophotos with automatic radiometric blending and seamline optimization. Exports as standard GeoTIFF with full world/projection files (.pgw, .prj) for instant QGIS/ArcGIS ingestion.

NodeODM Core GeoTIFF / KML / KMZ

LiDAR & Ground Classification

Ingest multi-gigabyte LAS/LAZ files. Execute PDAL SMRF terrain filtering, extract bare-earth Digital Terrain Models (DTM), non-ground building structures, and generate precise elevation contours.

PDAL SMRF Engine LAS / LAZ 1.2 & 1.4

3D Gaussian Splatting

Step beyond polygon limitations. Harness NVIDIA CUDA and Nerfstudio (Splatfacto) to train photorealistic radiance fields, producing continuous, high-definition 3D splats (.ply) with real-time inspection.

Nerfstudio / CUDA PLY Radiance Fields

Integrated RTKLIB & GCP Solver

Built-in local PPK engine using RTKLIB for rover/base RINEX processing. Interactive Ground Control Point (GCP) marking with sub-pixel bundle optimization and custom projected metric Coordinate Systems (EPSG).

RTKLIB EX 2.5.1 RINEX / POS / GCP CSV

Multispectral Vegetation Indices

Automated band calibration and calculation for NDVI, NDRE, VARI, and GNDVI indices. Generate clear false-color stress maps to monitor crop vigor, nitrogen status, and canopy density.

Radiometric Calibrated NDVI / NDRE / VARI

2D & 3D Web Tiling Packages

Export Web Mercator XYZ tiles (zoom up to 24) in ZIP/MBTiles for offline web maps. Produce OGC 3D Tiles (PNTS point clouds and B3DM meshes) for instant Cesium and web-based 3D geospatial viewers.

OGC 3D Tiles Ready MBTiles / XYZ / PNTS
